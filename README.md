## Selected projects

### [restaurant-crm](https://github.com/IvanSytnik/restaurant-crm) — reservation CRM and public booking site
A production reservation system used by a restaurant in Graz, replacing a paid booking SaaS. Best-fit table allocation with conflict detection and turnover buffers, a real-time floor plan, role-based access control, a trilingual DE/EN/UK interface and transactional email.

`Next.js 15 · TypeScript · Prisma · PostgreSQL · NextAuth · next-intl · Resend · Vercel`  
→ [Live site](https://restaurant-crm-ten.vercel.app)

### [Universal-Media-Downloader](https://github.com/IvanSytnik/Universal-Media-Downloader) — async media processing platform
Clean architecture with a strict dependency rule, so new clients (REST, web) can be added without touching domain logic. Heavy work runs in an arq worker, each job isolated in its own OS process for reliable cancellation. Files up to 2 GB via a self-hosted Telegram Bot API server, domain-level error classification and localized messages.

`Python 3.13 · aiogram 3 · yt-dlp · FFmpeg · SQLAlchemy 2 (async) · PostgreSQL · Redis · arq · Docker · mypy strict`

### [styleme](https://github.com/IvanSytnik/styleme) — AI hairstyle try-on SaaS
Users upload a selfie and preview hairstyles generated by an image model. Abuse protection lives on the server: per-user and per-IP quotas in Redis, and a nonce-based flow for rewarded credits, so the client is never trusted with balances.

`Next.js 16 · React 19 · TypeScript · Express · Supabase (Postgres + RLS) · Redis · Replicate · Vitest · Playwright`  
→ [Live demo](https://styleme-second-v-web.vercel.app)

### [english-learn](https://github.com/IvanSytnik/english-learn) — adaptive English learning platform
An adaptive exercise-selection engine built on Bayesian Knowledge Tracing with an IRT emission model, FSRS spaced repetition and concept-level Thompson Sampling. Learner state is append-only and event-sourced, with one pure fold shared by the live path and replay; deterministic by construction through an injectable seeded RNG.

`TypeScript · Next.js · Prisma · PostgreSQL · Turborepo · Vitest · fast-check`
