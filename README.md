## What I'm working on

### [restaurant-crm](https://github.com/IvanSytnik/restaurant-crm) — reservation CRM and public booking site

A production reservation system currently used by a restaurant in Graz, replacing a paid booking SaaS. Includes best-fit table allocation with conflict detection and turnover buffers, a real-time floor plan, role-based access control, a fully trilingual DE/EN/UK interface and transactional email.

`Next.js 15 · TypeScript · Prisma · PostgreSQL · NextAuth · next-intl · Resend · Vercel`

→ [Live demo](https://restaurant-crm-hwdr.vercel.app/de)

### [english-learn](https://github.com/IvanSytnik/english-learn) — adaptive English learning platform

An adaptive exercise-selection engine built around Bayesian Knowledge Tracing with an IRT emission model, FSRS spaced repetition and concept-level Thompson Sampling. Learner state is append-only and event-sourced, with a single pure fold shared by the live path and replay. Deterministic by construction through an injectable seeded RNG.

`TypeScript · Next.js · Prisma · PostgreSQL · Turborepo · Vitest · fast-check`

### [Universal-Media-Downloader](https://github.com/IvanSytnik/Universal-Media-Downloader) — async media processing platform

Built around clean architecture with a strict dependency rule, allowing REST and web clients to be added without changing domain logic. Heavy work runs in an arq worker, with each job isolated in its own OS process for reliable cancellation. Includes domain-level error classification and localized user-facing messages.

`Python 3.13 · aiogram 3 · FastAPI · SQLAlchemy 2 (async) · PostgreSQL · Redis · arq · Docker · mypy strict`

`Next.js · TypeScript · FastAPI · PostgreSQL`
